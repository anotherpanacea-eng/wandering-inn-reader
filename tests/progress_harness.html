Source progress checks

Open the reader in another tab. Use an invented local text file with one long paragraph and a second same-title file with different text. This harness makes no automatic changes.

  1. Import and scroll halfway through the long paragraph: Position advances and the 200 words/min assumption is visible.
  2. Search a phrase, navigate to a note, change font/measure/mode and resize. Reload/resume: the saved source point remains.
  3. Finish book, reload and change layout: 100%/0 minutes stays until an earlier reading/navigation gesture.
  4. Open the shelf: committed position agrees. The two same-title books remain separate.
  5. Exercise blocked storage, invalid legacy offsets and deletion/reimport from another tab: failure labels appear, drafts/notes survive and stale precise writes cannot recreate books.
  6. Check keyboard focus on Finish book, local search and paused audio behavior. No content should appear in network requests or URLs.
