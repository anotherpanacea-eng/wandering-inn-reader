## Source position and percentage
Use original admitted segments[].text, never rendered text, layout pixels, audio duration or number of segments as the denominator. A point is {seg,offset}, where seg is a safe integer identifying a source segment and offset is a UTF-16 boundary between complete Unicode code points. Count Unicode code points across all source segment strings, including their whitespace; do not invent intersegment separators or include title/chapter headings. This is source position, not comprehension or a word-count completion claim.

For total T code points and point prefix C, display floor(100*C/T)% as **Position**. Ordinary character anchors identify a source character, so C<T and the display stays below100. Source prefix counts are ordinary computed values, not a persisted cache. Empty-text books show progress/time unavailable, never divide by zero or claim complete.

Reuse current character Range/column geometry to find the first complete source character at the reading anchor: scroll uses the existing quarter-height reading anchor; paged mode uses the first source character in the displayed column. Validate the complete rendered segment against source and normalize a surrogate-interior candidate to its preceding code-point start, then recheck actual geometry. A fallback segment/page guess cannot establish a new precise position. If geometry cannot be proved, retain the previous valid point and show position unavailable for the current view; never persist guessed offsets. Reflow retains the same point when no reading/navigation gesture changes place.

Author proposal for reaching the boundary: a labeled **Finish book** action records the source end boundary {seg:last nonempty segment,offset:its text.length}, displays100% and zero minutes. This is an explicit user-reported finish, not automatic evidence of reading. Mere visibility of the final paragraph or an initial one-page book never marks finished. Moving to any earlier source character clears this end position. Reopen of an end position shows the final source character with the finished status retained until a reading/navigation gesture; opening/settings/reflow alone do not clear it.

## Persistence and navigation
Extend the existing position object with optional offset; keep seg for old code. No new schema family or change to admitted segment documents. Legacy {seg} positions are readable at that segment's first valid source boundary, labeled approximate until a genuine character anchor or explicit navigation establishes an offset. Invalid offset values do not poison the book or annotations: use the legacy segment restore as approximate, do not claim exactness or overwrite merely on open. Missing/invalid seg continues existing genericRestoreSeg behavior, also approximate. Preserve optional unknown position fields on read; an intentional new position write may replace only its own position fields.

Use the admitted book identity, immutable annotation book-instance binding from draft60, admitted generation and ordered source texts for position writes. Fresh readmodifywrite in the existing transaction must preserve annotations, instance and other metadata; a removed/reimported lifetime cannot be recreated or overwritten by an old queued save. No new lifetime mechanism. If the instance is unavailable, ordinary legacy segment saving remains operational but precise position persistence is unavailable and honestly labeled. Successful commit alone establishes saved status. Abort/missing book/source change retains prior stored point and existing unsaved/error behavior.

Search and annotation navigation use their validated exact source offsets rather than subsequently replacing them with segment start. Scroll/page gestures capture a fresh point; font/measure/mode/viewport changes preserve the point and reconstruct geometry before updating the display. Reopen navigates to its saved offset using fresh geometry; geometry failure retains the stored point and reports failure without overwriting it. Source changes retain draft60 annotated-reimport refusal. For a same-identity changed source without annotations, reset precise offset to legacy approximate segment position rather than reusing an offset from different text. Same-source reimport preserves precise position and finish boundary.

Shelf computes position from the persisted source/point, labels legacy values approximate, and agrees with the open reader after a successful save. Per-book identity isolates same-title books. Transient view position and saved position are distinguished on storage failure; do not show an unsaved estimate as a persisted shelf update. No per-gesture history or cloud library sync. Existing Dropbox audio/playlist position sync is untouched.

## Estimated time-left
Author proposal: fixed200 whitespace-delimited source words/minute; no claim that this is Joshua's measured pace. Display **Estimated time left: N min at 200 words/min** beside position, and explain the assumption in docs. This needs no pace settings or monitoring. A word is a maximal JavaScript /\S+/u match in each original segment; count a word as remaining when its end offset is after the current point, so a partly traversed word remains one word. N=ceil(remaining/200). An explicit finished source-end point is0. Empty/whitespace-only source has no useful word estimate and shows unavailable, even when character position exists. Legacy approximate points produce an explicitly approximate estimate. These simple author-selected presentation policies require review, not speculative calibration machinery.
